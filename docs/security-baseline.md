# TradeTrust AI - Security Baseline

1. Never expose PayPal secrets to browser code.
2. Use PayPal Sandbox only during development.
3. Derive payment amounts from trusted server data.
4. Never trust AI-generated financial instructions.
5. Require explicit buyer approval before payment.
6. Verify PayPal webhook signatures.
7. Protect against duplicate payment operations.
8. Validate all untrusted inputs.
9. Prevent prompt-injection-driven tool execution.
10. Apply least privilege to all integrations.
11. Use synthetic data for testing.
12. Never reuse client production credentials.
13. Add automated functional and security tests.
14. Review dependencies and licenses.
15. Keep production deployment disabled by default.
