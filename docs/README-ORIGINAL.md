# TradeTrust AI

Guardrailed Agentic Commerce for Cross-Border Sellers.

## PayPal AI Hackathon 2026

An original, standalone hackathon project.

## Core Objective

Build an AI-assisted commerce application with
validated orders, explicit human payment approval,
PayPal Sandbox integration, and auditable transactions.

## Current Status

Foundation initialized.
Application implementation has not started.

## Security Requirements

- OWASP-aligned secure development
- Server-side validation of all financial amounts
- Human approval before payment
- No secrets committed to Git
- Verified payment webhook processing
- Idempotent transaction handling
- Least-privilege access controls
- No production payment credentials
- Isolated infrastructure
